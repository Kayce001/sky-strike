# 星际突击

在线游戏：[开始游玩](https://kayce001.github.io/sky-strike/)

支持键盘、鼠标和触屏操作，并显示累计玩家和正在游玩人数。

## 统计口径

- 点击开始任务后首次登记累计玩家。只浏览首页不增加累计数。
- 使用浏览器 localStorage 中的随机匿名 ID 去重；重复开局、刷新和同浏览器多个标签页不重复累计。
- 不要求登录，因此更换设备、浏览器、无痕窗口或清除本地数据可能被视为新玩家；禁用本地存储时只在当前页面内去重。
- 在线人数统计正在游戏且页面可见的玩家，同一匿名玩家的多个标签页只计一个人。
- 暂停、游戏结束、切换标签页和正常离开时主动离线。异常断网在 45 秒无心跳后判定离线，其他页面每 15 秒刷新一次显示。
- 从统计功能启用时开始记录，无法补回启用之前的玩家数。
- 服务故障时显示“—”，不伪造为 0，游戏仍然可以正常游玩。
- 属于匿名游戏使用统计，不是经过账号认证的人数。

## 验证

Node.js 24 或更新版本：

```sh
npm test
```

测试使用临时内存 SQLite 数据库，覆盖去重、在线过期、多标签页、乱序请求、参数校验及故障恢复，不修改线上统计。
